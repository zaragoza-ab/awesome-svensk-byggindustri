## Contributing

Pull requests welcome! Keep these principles:

- **Open first** — Prefer free/open resources over paywalled ones
- **Swedish context** — Entries should be directly relevant to the Swedish construction industry
- **No commercial spam** — Tool vendors OK if their product is genuinely useful, no sponsored listings
- **Legal grounding** — Law references must be current
